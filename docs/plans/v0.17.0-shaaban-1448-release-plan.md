**B2. Currency consolidation — LARGER than scoped**
The plan says "19 files". Verified:
- **65** files reference `formatCurrency` / `getSupportedCurrencies` / `currencyNormalization` / `fxRate`
- **42 separate local `formatCurrency` definitions** exist across components and pages

That is the real source of #310-class bugs: every one of those 42 is an independent chance to hardcode `'USD'` or drop the user's currency. Consolidate toward the existing canonical `client/src/utils/formatters.ts::formatCurrency` (and `useDisplayCurrency`), then delete the local copies. This is the highest-value refactor in the plan; scope it as its own PR series, not one ticket.
