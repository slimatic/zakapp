# ZakApp v1.0 — Nur and Qamar

**20 Rabi al-Thani 1448 — waning gibbous, 70% lit**

ZakApp v1.0 is the release where the app starts to feel like one thing. The design
has a name, the numbers come from a single source, and the interface works on a
phone and reads properly in Arabic. Nothing was rebuilt for its own sake.

## A design language, not a coat of paint

- **Nur** (light) and **Qamar** (dark) — a documented token set rather than
  ad-hoc colours. The switch now sits on the sign-in screen too, so a new user can
  choose a comfortable mode before they have an account.
- **The moon-arc** is this release's signature element. The *hawl* — the lunar year
  a Muslim waits before zakat falls due — is drawn as an arc filled to the current
  day, with the moon's phase reflecting the portion completed. It is the app's
  central metaphor rendered literally, and it replaces a bare progress bar.
- **A proper app shell.** A sidebar on desktop, a bottom tab bar on a phone, a
  drawer in between. The dashboard was rebuilt around the arc instead of
  accumulating cards.

## The numbers, from one source

- **One nisab basis, derived from the school you follow** — not a separate
  preference that could disagree with it. A redundant second switch was removed
  rather than left to drift.
- **An unanswered asset no longer overrides your school.** Silence is not a ruling.
- **Analytics and payment reminders refuse to guess.** Where an amount cannot be
  read, the app says so instead of substituting a number. An invented figure in a
  zakat calculation is worse than a blank one.

## Your data, in and out

- **Export before you upgrade.** Take a backup from Settings and restore or merge
  it afterwards if anything looks wrong. Import can replace or merge, and it
  carries the encryption key with it.
- **Asset values now have history.** An amount records the date it was true, so a
  portfolio reflects what you held rather than only what you hold now.
- **Clearing your data requires a backup first.**

## Arabic and Urdu, properly

RTL is not an edge case for this app, so it is not treated as one. Desktop pages in
Arabic no longer scroll sideways, and the check that verifies it runs in the suite
rather than being something someone remembered to do once.

## Known gaps

A release note that lists only wins is not worth reading, so:

- **Tablet widths (768–1024px) are not covered by the automated layout checks,**
  which measure phone and desktop only. Noted rather than quietly skipped.
- **One fiqh question is open:** whether the default nisab convention should be the
  gold or the silver basis. Both are available and the default preserves existing
  behaviour, so nothing changes for you meanwhile. It is going to qualified
  teachers rather than being settled in a changelog.

## Upgrading

Read [`UPGRADING.md`](../UPGRADING.md). The short version:

1. Export your data.
2. Take the new image.
3. If anything looks wrong, import the export.
